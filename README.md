# homework_02
开源文化运动课程期末实践作业

## 项目简介
本仓库完成GitHub开源协作相关实验，练习Git分支管理、制造并解决合并冲突、远程推送、Issue讨论、Pull Request等开源协作操作。

## 仓库信息
- 主分支：main，保存项目稳定版本
- 开发分支：dev，用于功能开发与修改测试
- 开源许可证：MIT License

## 实验内容
1. 初始化GitHub公开仓库，添加MIT许可证
2. 创建dev开发分支，模拟多人编辑产生文件合并冲突，并手动解决冲突
3. 将本地分支推送至GitHub远程仓库
4. 使用Issue模拟开源社区互动交流
5. 学习Pull Request代码合并评审工作流
